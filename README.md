# Video Game Sales Analysis

## About the Project

Video games are popular all around the world, but not every game performs equally well in the market. Some games become bestsellers, while others perform better in certain regions or on specific platforms. This project helped me explore video game sales data and understand the factors that make different games successful.

Using Python, I analyzed video game sales across different platforms, genres, publishers, and regions. I also explored sales trends over the years to understand how gaming preferences and market performance have changed.

## Project Objectives

The main goal of this project was to understand video game sales and identify useful patterns in the data. I worked on finding the best-selling games worldwide, comparing sales across platforms and genres, studying publisher performance, and understanding the differences in gaming preferences across various regions.

## Dataset Description

The dataset contains details about video games, such as game name, platform, release year, genre, and publisher. It also includes sales figures for North America, Europe, Japan, other regions, and global sales. I used these details to compare sales performance and explore different trends in the gaming industry.

## Tools and Technologies

I used Python in Jupyter Notebook to complete this project. Pandas helped me clean, organize, and analyze the data, while Matplotlib and Seaborn helped me create graphs and charts to present the results in a clear and understandable way.

## Work Performed

I started by exploring the dataset and checking for missing values. Then, I used descriptive statistics to understand the data better. I identified the top-selling games based on global sales and compared the performance of different gaming platforms and genres.

I also analyzed sales trends over different years, explored which publishers performed well, and compared sales across North America, Europe, Japan, and other regions. To make the analysis easier to understand, I created visualizations such as bar charts, histograms, box plots, and stacked bar charts.

## What I Learned

While working on this project, I gained practical experience with Pandas, data cleaning, grouping, sorting, aggregation, and data visualization. I also improved my understanding of exploratory data analysis and learned how to use data to identify patterns and answer business-related questions.

## Conclusion

This project gave me an opportunity to apply my Python skills to a real-world data analysis problem. By exploring video game sales across different platforms, genres, publishers, and regions, I developed a better understanding of sales patterns and gaming market preferences. Overall, this project helped me improve my analytical thinking and build confidence in working with data.
